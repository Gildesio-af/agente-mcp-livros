# Agente MCP Livros

Projeto de demonstração de um agente integrado ao GitHub Copilot SDK e a ferramentas MCP.
O repositório inclui uma skill para pesquisar livros e produtos em sites de vendas,
organizar dados verificáveis e gerar relatórios em Markdown.

## Conteúdo

- `skills/pesquisa-produtos/`: definição da skill de pesquisa de produtos.
- `.github/skills/pesquisa-produtos/`: cópia da skill para uso como personalização do workspace.
- `resultado-busca.md`: exemplo de relatório gerado a partir de uma pesquisa na OLX.
- `PROMPTS.md`: análise da execução anterior e estimativa de consumo de tokens.
